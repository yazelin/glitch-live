## 街景循環-未採用.mp4

第二部循環影片，同一個角色走在霓虹街上。720×1280、10 秒、4.97 MB，
Gemini 生的（2026-09-12），右下角浮水印位置跟採用的那一部一樣。

**沒有採用，三個理由：**

1. **機位不對。** 第三人稱正面跟拍她走路，沒有任何一種主播設備會拍出那個機位，
   那是 MV 鏡頭不是開台。採用的那一部是她在直播間對鏡頭揮手，背景有麥克風、螢幕、椅子。
2. **循環會跳。** 首尾幀平均差 41.94，採用那一部是 10.83，四倍。
   她在邁步中途，相位沒對上，小畫面也看得出來一頓。
3. **招牌上的字是壞的。** 「商煨粜」「欢浪浪」「北索域房」「慈迴賊水濱」—— <!-- speak-tw-ok 這幾個字就是在舉證影片裡的壞字，含簡體是它的毛病不是這份文件的 -->
   AI 生的假漢字，而且混著簡體。這一格佔畫面很大，在手機上讀得到。
   採用那一部的螢幕是抽象光斑，沒有這個問題。

留著是因為它在別的地方可能有用（謝幕背景、宣傳片素材那一類）。
要用之前先處理第三點。
